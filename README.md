# 🍎 פירות העמק — Triple Digital Workforce (דמו)

דמו עובד של תהליך קליטת הזמנות בוואטסאפ, עד שלב בקשת התמונות (ללא חשבוניות),
על בסיס מסמכי ה‑PRD וה‑Flow Discovery.

## הפלואו

```
לקוח (0557118125, כרם קפיטל)
   │  הודעת הזמנה בשפה חופשית
   ▼
1. סיווג + פרסור עם Claude          (FR-01, FR-03, FR-05, FR-06)
2. אישור קבלה מיידי + מס' הזמנה      (FR-02) — כולל הנחיית "שינויים עד 14:00"
3. רשימת ליקוט מסודרת לפי אזורים     (FR-07) — עברית / English / ไทย / العربية
4. PDF נשלח לקבוצת הליקוט            (FR-10)
5. ריאקשן אימוג'י על ה-PDF           (FR-11) = הדף הודפס, הליקוט החל
6. בקשת תמונות משויכת להזמנה         (FR-12) — חברה, מס' הזמנה, תאריך
7. תמונות שנשלחות בתגובה מצורפות     (FR-13) — דף מסומן + משלוח ארוז
```

תוספות ושינויים (FR-09): לפני הדפסה — נוצר PDF מעודכן (גרסה 2); אחרי הדפסה —
התוספת נשלחת כתגובה (reply) על הודעת ה‑PDF בקבוצה, בדיוק כמו בתהליך הידני.

## דרישות

- Node.js 18+
- חשבון וואטסאפ (רגיל או ביזנס) שיריץ את הבוט — מתחברים בסריקת QR
- מפתח API של Anthropic (לפרסור ההזמנות)

> **למה לא ה‑API הרשמי של WhatsApp Business?** ה‑Cloud API של Meta לא תומך
> בקבוצות ולא בריאקשנים בקבוצות — והפלואו בנוי עליהם. לכן הדמו משתמש
> ב‑[whatsapp-web.js](https://wwebjs.dev) שמתחבר לחשבון וואטסאפ רגיל.
> שכבת הוואטסאפ מבודדת ב-`src/whatsapp/` וניתנת להחלפה.

## התקנה והפעלה

```bash
npm install
cp .env.example .env
# מלא ב-.env: ANTHROPIC_API_KEY, PICKING_GROUP_NAME (שם קבוצת הליקוט המדויק)
npm start
```

בהרצה ראשונה יוצג QR בטרמינל — סרקו אותו מהטלפון שמריץ את הבוט
(וואטסאפ ← הגדרות ← מכשירים מקושרים). אם שם הקבוצה שגוי, האפליקציה תדפיס
את רשימת כל הקבוצות בחשבון כדי שתעתיקו את השם המדויק.

### בדיקות בלי וואטסאפ

```bash
npm run test:pdf    # יוצר PDF לדוגמה (בלי שום טוקן) -> output/KC-DEMO-01/
npm run test:parse  # פרסור הודעת אמת עם Claude + יצירת PDF (דורש ANTHROPIC_API_KEY)
```

## הדגמה מלאה

1. שלחו הודעת הזמנה מהמספר `0557118125` אל המספר שמחובר לבוט, למשל:
   ```
   היי, ההזמנה למחר:
   2 קילו עגבניות שרי
   בננות 3 קילו רק אם הם בשלות
   מלון קטן 2
   6 קוטג (אם חסר אז גבינה לבנה)
   ```
2. הלקוח מקבל אישור קבלה עם מספר הזמנה.
3. בקבוצת הליקוט מתקבל PDF של דף הליקוט.
4. אחד מחברי הקבוצה מסמן ריאקשן (👍 או כל אימוג'י) על הודעת ה‑PDF.
5. הבוט שולח בקשת תמונות (לקבוצת התמונות אם הוגדרה, אחרת כתגובה בקבוצת הליקוט).
6. שולחים 2 תמונות בתגובה — ההזמנה מסומנת כמתועדת. ✅
7. אפשר גם לשלוח "תוסיפו עוד 2 אבטיחים" מהמספר של הלקוח ולראות את הטיפול בתוספת.

## מבנה הפרויקט

```
src/
  index.js              # נקודת כניסה: חיבור וואטסאפ, ניתוב אירועים
  config.js             # קונפיגורציה מ-.env
  ai/parser.js          # פרסור הודעות עם Claude (structured outputs)
  flow/orchestrator.js  # הפלואו העסקי: הזמנה→אישור→PDF→ריאקשן→תמונות
  orders/store.js       # מאגר הזמנות (JSON) + היסטוריית פעולות (FR-14)
  pdf/template.js       # תבנית HTML של דף הליקוט (RTL, 4 שפות)
  pdf/generator.js      # רינדור HTML→PDF עם Chrome headless
  whatsapp/client.js    # שכבת whatsapp-web.js (ניתנת להחלפה)
scripts/
  test-pdf.js           # בדיקת PDF בלי טוקנים
  test-parse.js         # בדיקת פרסור מקצה לקצה
output/<order-id>/      # PDF + תמונות תיעוד לכל הזמנה
data/orders.json        # מאגר ההזמנות
```

## מה בכוונה לא בדמו

- הפקת תעודות משלוח / חשבוניות (שלב 4 בפלואו — מחוץ לסקופ)
- ניהול ריבוי לקוחות (המספר 0557118125 ממופה קשיח ל"כרם קפיטל"; ההרחבה: טבלת לקוחות)
- CRM / מאגר מוצרים מסודר — הפרסור והתרגום נעשים ע"י המודל בכל הודעה

## ⚠️ הערה

whatsapp-web.js היא ספרייה לא רשמית. לדמו היא מצוינת; לפרודקשן כדאי לשקול
ספק כמו Green API או שילוב של ה‑API הרשמי במסלולים שאינם דורשים קבוצות.
